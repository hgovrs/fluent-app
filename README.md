# Fluent 🌱

Um app de prática de idiomas em **Flutter + Firebase**, com interface em português,
prática de inglês e funcionamento **offline, sem conta e sem assinatura**.
O Firebase é opcional para guardar e recuperar o progresso entre dispositivos.

As trilhas A1–C1 são de **prática parcial**, não cursos CEFR completos nem
certificação de proficiência.
